## Introduzione a Git (per giocare a *Oh My Git!*)
### Che cos’è Git?
Git è un **sistema di controllo di versione**. Serve per tenere traccia dei cambiamenti fatti a file e progetti nel tempo. È usato soprattutto dagli sviluppatori di software, ma può essere utile anche in altri contesti dove si lavora su file che cambiano nel tempo, come documenti, siti web o progetti collaborativi.
Con Git puoi:
* **Registrare ogni modifica** fatta ai file.
* **Tornare indietro** a versioni precedenti del progetto.
* **Lavorare insieme ad altre persone**, senza sovrascrivere il lavoro degli altri.
Immagina Git come una sorta di "macchina del tempo" per i tuoi file, che ti permette di vedere com'erano in passato, confrontare le modifiche, e collaborare in sicurezza.
### Una storia interessante: Linus Torvalds e la nascita di Git
Git è stato creato nel **2005 da Linus Torvalds**, il celebre creatore del **kernel Linux**, il cuore del sistema operativo GNU/Linux.
All’epoca, il progetto Linux veniva gestito usando un sistema di controllo di versione commerciale chiamato **BitKeeper**. Tuttavia, a causa di disaccordi tra la comunità open source e l’azienda che sviluppava BitKeeper, l’accesso gratuito venne revocato.
Di fronte al rischio di perdere il controllo sul codice sorgente di Linux, Linus Torvalds decise di creare **un proprio sistema di versionamento**, gratuito, open source, **estremamente veloce e distribuito**, che non dipendesse da nessuna azienda.
In poche settimane, Torvalds scrisse la prima versione di Git, con l’obiettivo di soddisfare tre requisiti fondamentali:
1. **Velocità.**
2. **Gestione distribuita.**
3. **Integrazione sicura delle modifiche (merge) da tanti sviluppatori.**
Da quel momento, Git si è diffuso rapidamente ed è oggi lo **standard de facto** per la gestione del codice nei progetti software di tutto il mondo.
Un dettaglio curioso: il nome "Git" in inglese britannico è uno **slang ironico**, che può significare "idiota" o "fastidioso". Torvalds ha scherzato sul nome dicendo

> *"I'm an egotistical bastard, and I name all my projects after myself. First 'Linux', now 'Git'."*
### Perché imparare Git?
Git è uno degli strumenti fondamentali nel mondo della programmazione moderna. È usato in aziende, progetti open source e università. Impararlo ti permette di:
* Collaborare con altri in modo efficiente.
* Tenere organizzato il tuo lavoro anche su dispositivi diversi
* Evitare di perdere dati o di sovrascrivere file per errore.
